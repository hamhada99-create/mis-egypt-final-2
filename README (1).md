# قاعدة بيانات MIS-EGYPT

الملف `schema.sql` هو مخطط PostgreSQL للمشروع، ويغطي:
- الخطة الدراسية والسنة والفصول
- الصفوف والمواد والوحدات والدروس
- مصادر الدروس
- المفاهيم والأسئلة والاختيارات
- الاختبارات ومحاولات الطلاب والإجابات
- تقدم الطالب وXP والـ streak

شغّل المخطط على PostgreSQL قبل تفعيل API قاعدة البيانات.
