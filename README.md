# MIS-EGYPT — النسخة النهائية 2.1

منصة تعليمية عربية متكاملة مبنية بـ Next.js + PostgreSQL.

## ما تم تثبيته في النسخة النهائية
- إدارة المنهج: صفوف، مواد، وحدات، دروس، مفاهيم، مصادر.
- محتوى الدروس والملخصات والأهداف والأنشطة والأسئلة.
- بنك أسئلة واختبارات وربط الأسئلة بالاختبارات.
- حفظ المحاولات والنتائج والتقدم في PostgreSQL.
- تصحيح الاختبار على الخادم من مفتاح الإجابة المخزن في قاعدة البيانات، وليس من بيانات العميل.
- لوحة الطالب والتحليلات والتقدم.
- التعلم التكيفي وإتقان المفاهيم والتوصيات.
- لوحات المعلم وولي الأمر والإدارة.
- بحث وإشعارات وواجهة AI الحالية كطبقة جاهزة للربط بمزود نموذج فعلي.
- توحيد مخطط قاعدة البيانات في `database/schema-final.sql`.
- إزالة اعتماد واجهات قاعدة البيانات على جداول غير موجودة مثل `exam_templates`.
- عدم إرسال `is_correct` للطالب عند جلب الأسئلة.

## التشغيل
1. أنشئ PostgreSQL وضع `DATABASE_URL` في `.env.local` اعتماداً على `.env.example`.
2. نفّذ `database/schema-final.sql` على قاعدة البيانات.
3. نفّذ `npm install` ثم `npm run build` ثم `npm start`.

> ملاحظة: تسجيل الدخول الحالي ما زال Demo ويحتاج ربطه بنظام حسابات حقيقي قبل الإطلاق التجاري العام. باقي طبقة الاختبارات وقاعدة البيانات أصبحت جاهزة كأساس تشغيل فعلي.
